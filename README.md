# Casetech
كيستيك (CaseTech) هي منصة تجارة إلكترونية متطورة رائدة في مجال الحماية التكنولوجية وإكسسوارات الهواتف الذكية بالطلب (Print-on-Demand).. يعتمد نموذج عمل المنصة على التصنيع المرن والأتمتة السحابية الكاملة مع شبكة مقرات ومصانع لوجستية تضمن الشحن السريع لباب البيت مع الدفع عند الاستلام والمعاينة قبل الدفع
